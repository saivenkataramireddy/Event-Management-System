About Mana Events

Mana Events is a smart and efficient Event Management system built to simplify the process of organizing, managing, and tracking events seamlessly. From small celebrations to grand corporate functions, Mana Events helps users create, manage, and monitor events — all in one place.

🎉 Features

  • ✔ Add and manage multiple events
  • ✔ Track budgets and event locations
  • ✔ Manage users and their roles
  • ✔ Display all event details dynamically

⚙️ Admin Capabilities

  • ✔ View total events and users
  • ✔ Calculate total event budgets
  • ✔ Edit or remove event details
  • ✔ Manage event approvals
